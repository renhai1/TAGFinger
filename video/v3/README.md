# V3 visual-direction sample

This is a **core-method and visual-direction sample**, not the complete
supplementary video. The prior complete V2 overview is preserved.

Watch `../../images/TAGFinger_v3_sample.mp4`, or open `preview.html` locally.

## What is different

- A persistent 20-node graph with perspective projection, depth lighting,
  text-bearing paper nodes, smooth camera reframing, and animated edge flow.
- A selected graph region lifts away from the context; its document expands
  into the text edit rather than appearing as a new slide.
- The original word morphs into an edited word with reflow and highlighting;
  model-response bars change with the edit.
- Response evidence marks converge into a majority decision, retaining the
  distinction between zero evidence and a no-use verdict.
- More deliberate typographic scale, spatial hierarchy, supersampling,
  original low-level music bed and restrained transition sound accents.

The font, shading, camera, graphic geometry, motion paths, sound bed and
illustrations are generated by the editable `production.py` source. No
stock footage, external raster image, template slide, or external music is used.

## Scope

All graph examples, text edits, probability shapes and votes are **schematic**.
The text edit is not claimed to be an experimentally optimized fingerprint.
No verification-accuracy or alignment percentage appears in this sample.

The sample intentionally focuses on graph semantics, local text-edit
construction and task-wise evidence. It does not replace the full explanation
of SAKA, alternating prompt optimization, or experimental evaluation.

The synthetic voice is generated locally with Piper and the
`en_US-ljspeech-high` voice (the upstream model card identifies the training
dataset as the public-domain LJ Speech dataset). Voice models and external
packages are not bundled.

## Re-render

Re-rendering saved audio requires Python 3.11+, NumPy, Pillow, macOS Helvetica
Neue / Avenir Next / Menlo fonts, and FFmpeg with H.264 support.

```bash
python production.py stills
python production.py render --ffmpeg /path/to/ffmpeg
```

Default internal render: 2560×1440 at 30 fps, Lanczos-downsampled to
1920×1080, H.264 / 48 kHz AAC. The original mixed audio and cue timeline
are in `assets/mix.wav` and `assets/timeline.json`.

To regenerate voice after editing `storyboard.json`:

```bash
python production.py audio --refresh-audio \
  --voice-model /path/to/en_US-ljspeech-high.onnx \
  --voice-config /path/to/en_US-ljspeech-high.onnx.json
```
